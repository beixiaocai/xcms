## 项目简介

rebekah 是宇图瑞视自主研发的 AI 视频行为分析系统（v5 版本），采用 C++ 开发。用户无需关心音视频开发、编解码开发、界面开发等底层工作，只需训练自己的模型，即可快速实现所需的视频行为分析算法，例如：人脸检测、人脸识别、周界入侵、烟火检测、跌倒、人群聚集、电动车、离岗睡岗、安全帽、工作服、疲劳检测、交通拥堵等。

* 支持 x86 / arm 架构，Windows / Linux / Docker 运行环境
* 支持 NVIDIA 显卡、华为昇腾、瑞芯微 RK3588/RK3576、Jetson 等硬件后端
* 按路数授权，满足从少量通道到大规模部署的不同需求
